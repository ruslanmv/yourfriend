# Canonical companion posters

The launch build reuses the polished, reviewed light/dark companion renders preserved in `docs/reference-images/companion-integrated/`; Vite bundles those existing repository assets without adding duplicate binaries.

For the final licensed character release, add transparent AVIF/WebP exports from the canonical VRM here, update `src/config/avatar.ts`, and keep a static poster permanently for first paint, reduced motion, mobile devices, and WebGL failure. Poster renders must contain only the character—never scenery, text, or UI.
