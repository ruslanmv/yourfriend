# VRM redesign model library

The landing page now keeps a small verified VRM set in this repository so UI and
poster redesign work does not depend on another repository being online.

## Included CC0 redesign set

`public/avatar/models/cc0/` is generated by:

```bash
python scripts/vendor_open_vrms.py --all
python scripts/vendor_open_vrms.py --all --check-only
```

The current set contains:

- `AvatarSample_A.vrm` — current live hero baseline
- `AvatarSample_B.vrm`
- `AvatarSample_C.vrm`
- `fem_vroid.vrm`
- `masc_vroid.vrm`

`models.json` records source URLs, file sizes, GLB version, and SHA-256 hashes.
The source list mirrors the public CC0 VRoid sample downloads already used by
`ruslanmv/3D-Avatar-Chatbot`.

## Premium VRoid Hub candidates

The curated list is in `scripts/vroid_candidates.json`. VRoid Hub does **not**
allow a model download from only an Application ID and Secret: the application
must first complete the user's OAuth 2.0 authorization-code + PKCE flow and use
the resulting Bearer access token.

Credentials and tokens must never be committed. The repository ignores:

- `.env.vroid`
- `.vroid-oauth-session.json`
- `.vroid-token.json`

Local authorization:

```bash
export VROID_CLIENT_ID='...'
export VROID_CLIENT_SECRET='...'
export VROID_REDIRECT_URI='the exact redirect URI configured in VRoid Hub'

python scripts/vroid_oauth.py authorize
# Authorize the printed URL in a browser and copy the returned `code`.
python scripts/vroid_oauth.py exchange --code '...'

python scripts/download_vroid_candidates.py --list
python scripts/download_vroid_candidates.py --only avatar-sample-o
# or, after reviewing storage size:
python scripts/download_vroid_candidates.py --all
```

Before every download, `download_vroid_candidates.py` asks the live VRoid Hub API
for the model details and refuses models that no longer satisfy this project's
commercial/download policy. It saves the live license response beside each VRM.

After this branch is merged, `.github/workflows/vendor-vroid-hub.yml` can do the
same operation from GitHub Actions. Add the authorized access token as the
repository secret `VROID_ACCESS_TOKEN`, then run **Vendor licensed VRoid Hub
models** and select `avatar-sample-o` or `all`.

## Rendering for the landing page

Use the portrait crop for hero/poster work so a model's authored full-body rest
pose does not place its hands over the hips/thighs in the composition:

```bash
blender --background --python scripts/blender_vrm_render.py -- \
  --input public/avatar/models/cc0/AvatarSample_A.vrm \
  --output public/avatar/posters/avatar-sample-a.png \
  --framing portrait
```

Use `--framing face` for the small **VRM / VRMA + Procedural Motion** thumbnails.
